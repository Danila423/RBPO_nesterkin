Alerts

Strict-Transport-Security Header Not Set

API responses are served over HTTP without an HSTS policy which keeps downgrade attacks possible.

Samples: GET /, GET /health

Remediation: terminate TLS in front of the service and send Strict-Transport-Security: max-age=63072000; includeSubDomains.

X-Frame-Options Header Not Set

Pages such as /docs can be framed which enables clickjacking.

Remediation: return X-Frame-Options: DENY or CSP frame-ancestors 'none'.

X-Content-Type-Options Header Missing

Browsers may perform MIME-sniffing for OpenAPI and JSON responses leading to XSS surfaces.

Remediation: send X-Content-Type-Options: nosniff on every JSON response.

Content Security Policy (CSP) Header Not Set

The Swagger UI does not restrict script sources.

Remediation: publish a Content-Security-Policy tuned for the FastAPI docs.

Incomplete or No Cache-control Header

Token related responses (for example /token) do not prevent caching.

Remediation: return Cache-Control: no-store, max-age=0.
